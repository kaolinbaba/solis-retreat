# Solis Retreat — living landscape website

A concept website for a fictional wellness retreat, built to feel alive.

- **Living scene:** a still lake photograph animated in real time with WebGL — perspective-correct water swell, refraction over the shallow stones, glints on bright reflections, drifting horizon mist, slow light shafts, wind in the trees and a 10-second "breath".
- **Custom cursor:** a sun dot with a water-drop lens; it breathes over the water, opens into a halo on links, and leaves ripples on the lake.
- **Soundscape (opt-in):** generated with Web Audio — soft water at the shore, distant droplets and a warm, slowly evolving pad in a gentle room reverb.
- **Stay planner:** an accessible three-step demo flow. Nothing is booked, sent or stored.
- **Comfort:** pause-motion control, reduced-motion support, keyboard navigation, system cursor in text fields and dialogs.

Vanilla HTML, CSS and JavaScript. No frameworks, no build step.

> Solis Retreat is fictional. Property details are placeholders and the planner is a demo.
